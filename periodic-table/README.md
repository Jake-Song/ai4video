# 주기율표는 왜 이런 모양일까?

전자 상태의 규칙에서 출발해 주기율표의 모양과 화학적 성질을 설명하는
**화학 입문자용 한국어 영상**입니다. 어두운 배경 위에서 전자구름, 오비탈 점유,
원소 카드와 주기율표가 이어지고 실제 이온화 에너지 그래프로 주기성을 확인합니다.

- [완성 영상](./periodic-table.ko.mp4) — 11분 48.7초, 1920×1080, 30fps, H.264/AAC.
- [주기·족·바깥 전자 설명 60초 미리보기](./periodic-table-preview.ko.mp4).
- [한국어 대본](./script.ko.md) · [한국어 자막](./periodic-table.ko.srt).
- [영상 제작 전 수정 대본](./script-draft.ko.md) · [EBS 참고 구간과 반영 내용](./reference-notes.ko.md).
- [원소·전자배치·에너지 데이터](./facts.json) · [파일 검증 결과](./validation.json).

SunHi 한국어 내레이션, 화면에 표시되는 자막, 8개 챕터를 제공합니다.
도형과 애니메이션은 직접 작성한 Python 코드로 그립니다.

## 이야기

1. 표의 빈 공간과 반복되는 성질에서 질문을 시작합니다.
2. 양성자는 원소의 정체, 전자는 화학적 변화를 설명합니다.
3. 정상파 비유와 확률밀도로 허용되는 전자 상태를 소개합니다.
4. 한 오비탈의 두 전자, s와 p의 수용량으로 처음 세 주기를 만들고,
   **주기와 전자 껍질**, **족과 바깥 전자 수**를 연결합니다.
5. d·f 구역, 4s·3d 채움 순서, 헬륨의 위치를 연결합니다.
6. **왜 바깥 전자가 결합에 참여하는지**를 안쪽 전자와 비교하고,
   거리·차폐를 실제 제1 이온화 에너지의 반복에 연결합니다.
7. NaCl 결정과 H₂ 결합을 전기적 상호작용과 에너지로 설명합니다.
8. 답을 보기 전에 생각할 시간이 있는 두 질문으로 복습합니다.

## 다시 만들기

Python 3.13, FFmpeg/FFprobe(libass 포함), UnDotum·DejaVuSans 글꼴이 필요합니다.
`ai4video` 루트에서 실행합니다. Python 의존성은 루트의 `pyproject.toml`으로 관리하며, `uv sync`가 의존성 잠금 파일을 생성합니다. 음성 생성 단계는 새 한국어 대본 문장을
Microsoft Edge 온라인 음성 합성 서비스로 전송합니다.
저장된 음성이 있으면 이후 렌더링과 검증은 오프라인으로 실행할 수 있습니다.

```bash
# ai4video 루트의 공통 환경 설치
uv sync

# 대본 작성 → 음성 합성 → 타임라인/자막 → 화면 확인 → 렌더링 → 조립 → 검증
uv run ai4video.py run periodic-table draft
uv run ai4video.py run periodic-table audio
uv run ai4video.py run periodic-table sync
uv run ai4video.py run periodic-table preview
uv run ai4video.py run periodic-table render --jobs 4
uv run ai4video.py run periodic-table assemble
uv run ai4video.py run periodic-table check
```

`render --scene 13`은 0부터 시작하는 장면 번호 하나만 렌더링합니다.
`sync`는 저장된 음성으로 타임라인·대본·자막·챕터를 다시 만듭니다.
`preview`는 각 장면의 세 시점과 전체 콘택트시트를 저장합니다.
코드·데이터·대본·타이밍·글꼴의 해시가 바뀌면 장면 캐시를 다시 만듭니다.
음성 캐시는 대본·목소리 해시로 검증합니다.

`lesson.py`가 대본 원본이고, `visuals.py`가 시각화 원본입니다.
각 대본 구간의 실제 길이와 단어 경계를 저장해 자막과 원소 등장 시점을 맞춥니다.
`timing-budget.json`에 기존 32개 장면의 프레임 수와 음성 배속을 저장했습니다.
전체 **21,261프레임 / 30fps = 708.7초**, 배속 **약 1.073배**를 고정합니다.
수정 음성이 해당 장면 시간을 넘으면 대본 수정을 요구하고 중단합니다.
남는 시간은 장면 끝의 화면 유지 시간으로 사용하며 음성을 자르지 않습니다.
마지막 복습 질문 뒤에는 3초의 생각할 시간을 둡니다.
출력 음량 목표는 -16 LUFS, 최대 true peak 목표는 -1.5 dBTP입니다.

MP4·음성·클립·미리보기·로그는 로컬 산출물로 Git에서 제외합니다.
원본 코드, 대본, 자막, 타임라인, 공개 데이터와 검증 기록을 함께 관리합니다.

## 과학적 표현과 근거

- 상세 전자배치는 **기체 중성 원자의 바닥상태 H–Ca**에 한정합니다.
  NIST ASD 원본 응답을 `data/nist-h-ca.html`에 보관하며 20개 배치를 대조합니다.
  무거운 원소의 전자배치를 단순한 채움 알고리즘으로 추정하지 않습니다.
- 주기와 껍질의 연결은 첫 세 주기의 중성 원자로 설명합니다.
  주족 1·2족의 바깥 전자는 1·2개, 13–18족은 3–8개이며 헬륨은 2개입니다.
  이 대응을 전이 원소에 적용하지 않으며, 전이 원소의 d 전자도 결합에 참여할 수 있습니다.
- 그래프는 같은 NIST 자료의 제1 이온화 에너지(eV)입니다.
  He→Li, Ne→Na, Ar→K의 급락과 Be→B, N→O, Mg→Al, P→S의 하강을 보존합니다.
- 전체 표의 기호와 번호는 IUPAC의 118원소 체계를 따릅니다.
  아래 계열 La–Lu와 Ac–Lr는 각각 **15원소**이며, f 부껍질의 **14전자 정원**과 구별합니다.
  아래 계열 전체를 15칸짜리 f 오비탈로 표시하지 않습니다.
- 슬롯은 점유를 기록하는 칸입니다. 파울리 원리와 p 오비탈의 단독 점유 후 짝짓기를 적용합니다.
  수직 배열은 채움 기록이고 실제 에너지 준위의 높이를 계산한 그래프가 아닙니다.
  특히 4s·3d의 상대 에너지를 모든 원자에서 고정된 것으로 취급하지 않습니다.
- 단일 원자의 구름은 수소형 s·p 밀도에서 만든 설명용 그림입니다.
  밝기를 보기 좋게 조정했으며, 다전자 원자의 정확한 계산 결과나 크기 측정값이 아닙니다.
  2s 모양을 확대한 주족 비교는 분포 크기의 정성적 도식입니다.
- H₂ 그림은 두 1s형 진폭의 합으로 만든 결합 상태의 정성적 모형이고,
  곡선은 Morse 형태를 사용한 설명용 에너지 곡선입니다. 정량 분자 계산이 아닙니다.
  NaCl은 교대 전하를 가진 결정 격자의 2D 단면으로 표현합니다.
- 옥텟은 제한된 경험칙입니다. 결합을 원자의 의도나 전자 이동 하나만으로 설명하지 않습니다.
  결합 상태의 에너지 설명은 모든 반응의 자발성과 반응 속도를 판단하는 법칙을 대신하지 않습니다.

출처와 링크는 [대본의 참고 자료](./script.ko.md#참고-자료)에 함께 기록합니다.
원소 자료는 [IUPAC](https://iupac.org/what-we-do/periodic-table-of-elements/),
전자배치와 에너지는 [NIST ASD](https://physics.nist.gov/PhysRefData/ASD/ionEnergy.html),
설명상의 오개념 점검은 [RSC](https://edu.rsc.org/cpd/how-to-teach-ionic-bonding-at-14-16/4016663.article)를 참고했습니다.

## 검증 범위

`check`는 원소 번호·배치·점유 규칙·수치 자료, 대본과 음성 캐시의 일치,
자막 시각과 길이, 32개 장면의 연속성, 8개 챕터, 1080p/30fps,
기존 장면별 시간과 708.7초 길이 유지, AAC 음성, 미리보기 길이와 최종 파일 전체 디코딩을 확인합니다.
대표 화면의 시각 점검은 이 파일 검증과 별도로 수행합니다.
