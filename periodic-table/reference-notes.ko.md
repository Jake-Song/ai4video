# 참고 영상과 대본 반영

참고: [EBS 컬렉션 — 「원소, 주기율표를 알면 뭐가 좋아요?」, 취미는 과학 49화 확장판](https://youtu.be/dDte4j_lyww).
영상 길이는 48분 5초이다. 확인일은 2026-10-05이며, 공개 한국어 자동자막 1,475개 구간을 가져와 아래 대목을 확인했다. 자동자막의 원소명·용어 표기는 기존 IUPAC·NIST 자료와 대조했다.

원본의 교육 내용을 참고해 기존 영상에 맞는 문장과 도형으로 다시 구성했다. 대화체, 출연자 이야기와 실험 시연은 옮기지 않는다.

설명 범위와 표현은 다음처럼 정리한다.

- 주기와 껍질의 대응은 먼저 배운 **첫 세 주기의 중성 원자**로 보여 준다. 모든 원소의 실제 전자배치에 예외 없이 적용되는 규칙으로 확장하지 않는다.
- 주족의 1·2족은 바깥 전자가 1·2개, 13–18족은 3–8개이다. 헬륨은 2개이며, 전이 원소는 이 대응에서 제외한다.
- 껍질은 전자 상태의 분류이다. 충돌을 피하려고 전자가 서로 다른 원형 궤도를 돈다는 설명을 사용하지 않는다.
- 바깥 전자가 중요한 이유를 핵과의 거리, 차폐, 다른 원자와의 전자 이동·공유로 설명한다. 안쪽 전자가 화학에 아무 영향도 주지 않는다고 단정하지 않는다.
- 원본의 버스 비유 대신 기존 영상의 전자구름과 상태 표시를 사용한다.

## 시간과 제작 순서

1. `lesson.py`에서 전체 내레이션을 먼저 정리하고 `script-draft.ko.md`로 저장한다.
2. 기존 32개 장면의 프레임 예산과 음성 배속을 고정한다. 전체는 **21,261프레임 / 30fps = 11분 48.7초**이다.
3. 새 문장 음성을 실제 측정한다. 장면 예산을 초과하면 문장을 줄이고 다시 합성하며, 말끝을 자르거나 배속을 더 높이지 않는다.
4. 대본에 맞춰 그림·자막·완성 영상·60초 미리보기와 검증 기록을 갱신한다.
